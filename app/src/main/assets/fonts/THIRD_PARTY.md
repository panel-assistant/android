# Bundled font

`Roboto.ttf` is the variable Roboto from `google/fonts` at commit `389b770410cc0b7c21c85673bfa2077420fe7f65` (`ofl/roboto`, SHA-256 `d7598e12c5dbef095ff8272cfc55da0250bd07fbdecbac8a530b9b277872a134`), unmodified. Copyright 2011 The Roboto Project Authors, licensed under the SIL Open Font License 1.1 (`OFL.txt`).

The app uses it only on a panel whose system sans-serif is not Roboto, so text there has the width it has on every other panel.
